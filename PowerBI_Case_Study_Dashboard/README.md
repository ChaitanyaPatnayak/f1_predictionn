# Formula 1 Case Study — Power BI Analytics Dashboard

> **Safety Notice:** This folder (`PowerBI_Case_Study_Dashboard/`) is completely self-contained. 
> Your previous original Power BI files (`F1_Dashboard.pbix` and `F1_Dashboard.pbip`) in the main project directory remain **100% untouched and safe**.

---

## What is in this Folder?

1. **`PowerBI_Interactive_Dashboard.html` (Recommended for Presentation):**
   * Double-click this file to open an interactive Power BI-themed dashboard in your browser (Chrome/Edge).
   * Features interactive navigation tabs matching all 15 questions, live KPI cards, full high-res visual embeddings, and the Master Hypothesis Testing Table.
   * Click on any graph to zoom in full screen!

2. **`F1_Case_Study_Analytics.pbip` (Power BI Desktop Project):**
   * Can be opened directly in Microsoft Power BI Desktop.
   * Uses the updated Semantic Model connected to local data (`data/*.csv`) with zero hardcoded user paths.

3. **`data/` (All 8 Cleaned Relational CSVs):**
   * `Circuits.csv`
   * `Drivers.csv`
   * `HypothesisTests.csv` (contains all 15 exact updated statistical test results)
   * `Predictions.csv`
   * `Races.csv`
   * `Results.csv`
   * `Seasons.csv`
   * `AnalysisVisuals.csv` (master index of all visuals)

4. **`visual_assets/`:**
   * All 18 high-resolution case study charts and diagrams (Q1 to Q15 + EDA).
